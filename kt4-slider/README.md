# КТ №4. Слайдер

Собственный слайдер из обычных `div` (без `<input type="range">`). Бегунок перетаскивается мышью в заданном диапазоне, над ним всегда видно выбранное значение. На странице три слайдера с разными диапазонами и шагом.

## Как запустить

Открыть `index.html` в браузере. Сборка и сервер не нужны, страница работает и на GitHub Pages.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | три контейнера `<div class="slider">` с настройками в `data`-атрибутах |
| `style.css` | внешний вид: шкала, закрашенная часть, бегунок, подсказка со значением |
| `slider.js` | вся логика слайдера |
| `check.js` | автопроверка расчётов: `node check.js` |

## Как это работает

Настройки слайдера задаются в HTML: `data-min`, `data-max`, `data-step`, `data-value` (начальное значение) и `data-suffix` (единицы измерения, например `%` или ` ₽`).

`initSlider(root)` вызывается для каждого `.slider`. Функция читает `data`-атрибуты, создаёт внутри шкалу (`.slider__track`), закрашенную часть (`.slider__fill`), бегунок (`.slider__thumb`) и подсказку (`.slider__bubble`) и вешает обработчики событий.

События мыши:

| Событие | Где | Что делает |
| --- | --- | --- |
| `mousedown` | на бегунке | начинает перетаскивание: добавляет `mousemove` и `mouseup` на `document` |
| `mousemove` | на `document` | двигает бегунок за курсором через `moveTo(event.clientX)` |
| `mouseup` | на `document` | заканчивает перетаскивание и снимает оба обработчика |
| `click` | на шкале | бегунок прыгает в точку щелчка |

Обработчики `mousemove` и `mouseup` вешаются на `document`, а не на бегунок: так перетаскивание не обрывается, если курсор во время движения ушёл с бегунка или вообще за пределы слайдера. `event.preventDefault()` в `mousedown` отключает выделение текста при перетаскивании.

Расчёт значения:

- `valueFromX(clientX, trackLeft, trackWidth, min, max, step)` переводит координату курсора в значение: доля ширины шкалы `(clientX - trackLeft) / trackWidth` умножается на диапазон `max - min`. Координаты шкалы берутся из `getBoundingClientRect()`.
- `snap(value, min, max, step)` округляет значение до ближайшего шага и не даёт выйти за `min` и `max`. Для дробного шага (0.5) результат округляется через `toFixed`, чтобы не появлялись числа вроде `0.30000000000000004`.
- `render()` переводит значение в проценты и выставляет `left` бегунка и `width` закрашенной части. Подсказка лежит внутри бегунка, поэтому двигается вместе с ним без отдельного кода.

Дополнительно: на сенсорных экранах работают `touchstart` / `touchmove` / `touchend`, а у бегунка в фокусе значение меняют стрелки, `Home` и `End`.
