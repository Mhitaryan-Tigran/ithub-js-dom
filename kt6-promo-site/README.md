# ВОЛНА·7 — промо-сайт вымышленного аналогового синтезатора

Итоговый проект по курсу «JavaScript DOM». Многостраничный промо-сайт с динамическими эффектами: четыре страницы, на каждой есть анимация, которой управляют и мышь, и клавиатура. Только HTML, CSS и чистый JavaScript — без фреймворков, сборщиков, внешних библиотек, шрифтов и картинок. Вся графика нарисована SVG и `<canvas>` прямо в коде.

Открывается двойным кликом по `index.html` и работает на GitHub Pages в подпапке (все ссылки относительные).

## Концепция

Запуск вымышленного премиального продукта — семиголосного аналогового синтезатора «ВОЛНА·7». Арт-дирекшн: тёплый чёрный фон, горячий оранжевый акцент, крупная заглавная типографика, моноширинные подписи, плёночное зерно поверх страницы (SVG-фильтр `feTurbulence` в `body::after`). Сайт сам «звучит»: на главной клавиши клавиатуры играют настоящие ноты через Web Audio API.

## Структура

| Файл | Назначение |
|------|-----------|
| `index.html` + `js/home.js` | Главная: осциллограф на canvas и играющая клавиатура |
| `product.html` + `js/product.js` | Устройство: SVG-конфигуратор с отделками и ручками |
| `gallery.html` + `js/gallery.js` | Истории: горизонтальная галерея с драгом и параллаксом |
| `order.html` + `js/order.js` | Заказ: поле частиц на canvas и форма с живой валидацией |
| `js/common.js` | Общее для всех страниц: шторка-переход, подсветка меню, свечение за курсором, подсказки клавиш, появление блоков при скролле, разлёт букв заголовка, бегущая строка, счётчики чисел |
| `css/style.css` | Единая стилевая система: токены цветов в `:root`, сетка, компоненты, `prefers-reduced-motion` |

Все анимации на JavaScript построены на `requestAnimationFrame` и линейной интерполяции `lerp(a, b, t)` — значение каждый кадр чуть приближается к цели, поэтому движение плавное и «инерционное».

## Общий код — `js/common.js`

| Что | Как работает |
|-----|-------------|
| `RM` | `matchMedia("(prefers-reduced-motion: reduce)").matches`. Если пользователь попросил меньше движения, все скрипты либо пропускают анимацию, либо ставят значение сразу. CSS дублирует это медиазапросом, обнуляя длительности переходов. |
| `lerp(a, b, t)` | Возвращает точку между `a` и `b` на доле `t`. Используется во всех страницах для сглаживания. |
| Шторка `.curtain` | Оранжевый слой на всю страницу. При событии `pageshow` ему добавляется класс `is-open` внутри `requestAnimationFrame`, и CSS-переход сжимает его `scaleY` к нулю сверху. `pageshow` вместо `load` нужен, чтобы шторка открывалась и при возврате кнопкой «Назад» из кэша браузера. |
| Переход между страницами | На каждую ссылку, чей `href` оканчивается на `.html`, вешается `click`. `preventDefault()` отменяет мгновенный переход, в `<span>` шторки пишется имя целевой страницы (`data-label` ссылки или её текст), классы меняются на `is-closing` (шторка растёт снизу вверх), и `setTimeout` через 620 мс меняет `location.href`. При `Cmd`/`Ctrl`-клике перехват не делается, чтобы ссылка открылась в новой вкладке. |
| Активный пункт меню | Имя текущего файла берётся из `location.pathname`; ссылке с таким `href` добавляется `is-active`. |
| Свечение `.glow` | Мышиная анимация, общая для всех страниц. `mousemove` на `window` запоминает целевые координаты, а цикл `tickGlow` каждый кадр подтягивает к ним текущие через `lerp` с коэффициентом 0.08 и пишет `transform: translate(...)`. Получается мягкое отставание за курсором. При `RM` не запускается. |
| Подсказки клавиш `<kbd>` | `keydown` на `window` сравнивает `e.key` (пробел переименовывается в `Space`) и `e.code` с атрибутом `data-key` каждой `<kbd>` и добавляет совпавшим класс `is-hit` (оранжевая заливка и «нажатие» на 2 px). `keyup` снимает класс со всех. Так на каждой странице видно, какую клавишу сайт услышал. |
| Появление при скролле `.reveal` | `IntersectionObserver` с порогом 0.15: когда блок на 15 % в окне, ему ставится `is-in`, и CSS плавно поднимает его из прозрачности; после этого наблюдение за ним снимается. |
| Разлёт букв `.display` | Текст заголовка разбивается по словам, каждое слово — `<span class="word">` с `overflow: hidden`, каждая буква — `<span class="ch">`, которой выставляется `transition-delay` = номер буквы × 35 мс. Слова с номерами из `data-accent` получают оранжевый цвет. Через 400 мс заголовку добавляется `is-in`, и буквы по очереди выезжают снизу. |
| Бегущая строка `.ticker` | Содержимое строки дублируется (`innerHTML += innerHTML`), затем цикл `tickTicker` сдвигает её на 0.6 px за кадр; когда сдвиг достигает половины ширины, обнуляется — так петля бесшовная. |
| Счётчики `animateNumber` | Для элементов с `data-to` второй `IntersectionObserver` при появлении в окне запускает отсчёт от 0 до значения за 1.4 с с кубическим замедлением `1 - (1 - t)^3`; `data-decimals` задаёт число знаков, `data-suffix` — единицу (« дБ», « кг»). |

## Главная — `index.html`, `js/home.js`

Герой — заголовок «Волна семь», осциллограф во весь экран и клавиатура из тринадцати клавиш.

### Анимация мыши: осциллограф
`mousemove` на `window` переводит координаты курсора в доли окна `mouseX`, `mouseY` (0…1). В цикле `frame()` они сглаживаются в `smoothX`, `smoothY` через `lerp`. Пока ноты не играют, рисуется синтетическая волна — сумма трёх синусов: `smoothX` задаёт частоту (от 2 до 12 периодов на ширину), `smoothY` — амплитуду (вверху экрана волна больше), а `phase` каждый кадр растёт, и волна течёт. Когда играет хотя бы одна нота, `AnalyserNode.getFloatTimeDomainData` отдаёт настоящий звуковой сигнал, и рисуется он. `drawLine()` вызывается четыре раза с разной толщиной и прозрачностью — так получается свечение. Ещё `smoothX` управляет частотой среза фильтра `cutoffFromMouse()` — двигая мышь вправо, вы «открываете» звук.

`resize()` подгоняет `<canvas>` под размер и `devicePixelRatio`, чтобы линия была резкой на Retina.

### Анимация клавиатуры: игра нот
`keydown` на `window` (с защитой от автоповтора `e.repeat`) ищет клавишу по `e.key` в словаре `keyByLetter` (A W S E D F T G Y H U J K — как на пианино, белые в среднем ряду, чёрные в верхнем) и вызывает `noteOn(key)`. `keyup` — `noteOff(key)`.

`ensureAudio()` лениво создаёт `AudioContext` при первой ноте (браузер разрешает звук только после действия пользователя): цепочка `filter → master → analyser → destination`. `noteOn` создаёт `OscillatorNode` с частотой `261.63 · 2^(n/12)` (от до первой октавы по полутонам) и огибающую `GainNode`, за 15 мс поднимает громкость, подключает в фильтр и запоминает голос в `Map`. На клавишу ставится класс `is-on` — она становится оранжевой и «вдавливается». `noteOff` плавно гасит громкость за 350 мс, останавливает осциллятор и снимает класс.

`Shift` перебирает форму волны (пила → меандр → треугольник → синус) у всех звучащих голосов и показывает текущую в правой колонке.

Мышью тоже можно играть: `mousedown` на клавише — `noteOn`, `mouseup` и `mouseleave` — `noteOff`, а `mouseenter` с зажатой кнопкой (`e.buttons === 1`) позволяет вести глиссандо по клавишам. `blur` окна глушит все голоса, чтобы нота не «зависла» при переключении вкладки.

### Остальное
Разлёт букв заголовка, бегущая строка с преимуществами, блок «Звук, который слышно кожей» с `.reveal`, три счётчика (7 голосов, 24 дБ, 4.2 кг) — всё из `common.js`.

## Устройство — `product.html`, `js/product.js`

Слева — большой SVG синтезатора, справа — конфигуратор. Клавиши и ручки синтезатора рисуются из JavaScript функцией `el(tag, attrs)` (обёртка над `document.createElementNS`), чтобы не писать десятки одинаковых прямоугольников руками.

### Анимация мыши: наклон 3D
`mousemove` на секции `.stage` считает положение курсора относительно секции и ставит цели `targetX`, `targetY` (до ±12° и ±18°). Цикл `tickTilt` каждый кадр подтягивает `tiltX`, `tiltY` через `lerp` и пишет `transform: rotateX() rotateY()`; у родителя стоит `perspective: 1600px`, поэтому SVG наклоняется как объёмная панель. `mouseleave` возвращает цели в ноль, и синтезатор плавно выравнивается.

### Анимация мыши: вращение ручек
На каждой `<g class="knob">` висит `pointerdown`: запоминаются `clientY` и текущее значение, на `window` вешаются `pointermove` (значение = стартовое + сдвиг вверх × 0.6) и `pointerup` (снимает оба слушателя). `setKnob()` ограничивает значение 0…100 и вызывает `renderKnob()`: угол стрелки `−135° + значение × 2.7°` ставится атрибутом `transform="rotate(...)"`, а оранжевая дуга вокруг ручки пересчитывается функцией `polar()` в команду `A` для `<path>`. Затем `renderScreen()` перерисовывает волну на экранчике синтезатора: Cutoff задаёт частоту синуса, Resonance — амплитуду.

### Анимация клавиатуры: отделки и ручки
Один `keydown` на `window`:
- цифры `1`–`4` — `setFinish(i)`: смена отделки (графит, слоновая кость, закат, полночь);
- `↑`/`↓` — `setActive()`: выбор активной ручки (она подсвечивается оранжевым кольцом, а её строка в списке значений — оранжевым текстом);
- `←`/`→` — `setKnob()` на ±2 у активной ручки; `preventDefault()` не даёт стрелкам скроллить страницу.

`setFinish` не просто меняет цвет, а морфит его: `morphColor()` переводит оба hex в RGB (`hexToRgb`) и за 700 мс через `requestAnimationFrame` и `lerp` по каждому каналу пишет промежуточный `rgb(...)` в атрибут `fill` корпуса, панели и надписей. Одновременно `ripple()` создаёт `<div class="ripple">` цвета новой отделки в точке клика (или в центре экрана, если нажата цифра) и за 700 мс раздувает его до размера диагонали окна, гася прозрачность, после чего удаляет. Кружки-свотчи под заголовком дублируют цифры для мыши (`click`), а экранчик синтезатора показывает имя отделки.

### Остальное
Сетка из шести карточек «Что делает звук» с иконками SVG появляется через `.reveal` с задержками 0 / 0.1 / 0.2 с по колонкам.

## Истории — `gallery.html`, `js/gallery.js`

Шесть слайдов-иллюстраций во всю высоту экрана. Каждый — SVG из нескольких слоёв `<g class="layer" data-depth="…">`: концентрические круги и солнце, лучи прожекторов, волны на светлом фоне, древесина с ручками, матрица точек и ночное небо. Точки и звёзды генерируются в скрипте циклами, чтобы HTML не раздувался.

### Анимация мыши: перетаскивание и параллакс
Драг через Pointer Events на контейнере `#trackWrap`: `pointerdown` запоминает стартовую координату и захватывает указатель (`setPointerCapture`), `pointermove` считает `dragOffset` и мгновенную скорость `velocity`, `pointerup`/`pointercancel` вызывают `endDrag()`: если сдвиг плюс скорость × 6 больше четверти ширины слайда — переход на следующий или предыдущий, иначе возврат. Лента не следует за пальцем жёстко: цикл `tick()` каждый кадр интерполирует `x` к `targetX + dragOffset` с коэффициентом 0.12, поэтому и драг, и прилипание к слайду получаются мягкими.

Параллакс: `mousemove` на контейнере даёт положение курсора −0.5…0.5, тот же цикл сглаживает его в `px`, `py` и для каждого слоя активного слайда ставит `transform="translate(...)"`, умноженный на `data-depth`. Дальние слои (глубина 0.2–0.4) едва двигаются, ближние (1) — заметно, и картинка становится объёмной. `mouseleave` возвращает слои на место.

### Анимация клавиатуры: листание
`keydown`: `→`/`←` — `goTo(index ± 1)`, `Home`/`End` — первый и последний слайд. `goTo()` ограничивает индекс, считает `targetX` так, чтобы активный слайд встал по центру (`centerOffset()`), обновляет счётчик `01 / 06`, двигает оранжевый отрезок прогресса (`translateX(index × 100%)`) и ставит остальным слайдам класс `is-far` (они приглушаются и чуть уменьшаются CSS-переходом). Кнопки-стрелки внизу делают то же по `click`, `resize` пересчитывает позицию.

## Заказ — `order.html`, `js/order.js`

Фон — поле частиц на фиксированном `<canvas>`, поверх — форма предзаказа со стеклянным фоном и колонка контактов.

### Анимация мыши: частицы
`buildField()` расставляет точки сеткой с шагом 34 px (40 на узких экранах), у каждой есть «дом» `hx, hy`, позиция и скорость. В `drawField()` каждый кадр: если курсор ближе 160 px, точка получает толчок от него, пропорциональный близости; затем пружина тянет её к дому (`(hx − x) × 0.02`), скорость гасится множителем 0.88, позиция обновляется. Цвет и радиус зависят от смещения `off`: на месте точка тусклая кремовая, сорванная — крупная оранжевая. `mousemove` на `window` обновляет координаты курсора, `mouseleave` уводит его за экран. `mousedown` вне формы и меню вызывает `explode()` в точке клика.

### Анимация клавиатуры: взрыв и форма
`keydown` на `window`: `Space` (если фокус не в поле ввода) — `explode()` из точки курсора: каждой частице добавляется скорость от центра взрыва, тем больше, чем ближе она, плюс немного случайности; дальше пружина возвращает всех домой. `Escape` — `reset()`: поля очищаются по очереди с задержкой 90 мс, снимаются классы валидации, прячется экран «Принято», фокус возвращается в имя.

`keydown` на форме: `Enter` в имени или почте переводит фокус в следующее поле (`inputs[i + 1].focus()`), `Enter` в последнем поле или `Cmd/Ctrl + Enter` где угодно — `submit()`. В текстовом поле обычный `Enter` оставлен для переноса строки.

### Живая валидация
`rules` — имя не короче двух символов, почта по регулярному выражению. `input` и `blur` на каждом поле вызывают `validate()`: обёртке `.field` ставится `is-ok` (оранжевая точка справа появляется через `@keyframes pop`) или `is-bad` (подпись ошибки выезжает в заголовке, граница становится оранжевой и поле трясётся `@keyframes shake`). `updateBar()` масштабирует оранжевую полосу вверху формы на долю заполненных полей.

### Цена и отправка
Кнопки-пилюли комплектации и отделки обрабатываются одним `click` на каждой группе `.pills` (делегирование через `closest(".pill")`): активная подсвечивается, `tweenTotal()` за 600 мс перебирает цифры от старой суммы к новой с кубическим замедлением и форматирует через `toLocaleString("ru-RU")`.

`submit()` (вызывается и событием `submit` формы с `preventDefault`) строго валидирует оба поля; если что-то не так — фокус в первое плохое. Иначе собирается текст подтверждения, экрану `.done` ставится `is-in`, а `drawStroke()` рисует круг и галочку: длина пути берётся `getTotalLength()`, ставится в `stroke-dasharray`, а `stroke-dashoffset` за 700 и 500 мс (галочка с задержкой 500 мс) уменьшается до нуля — линия «прорисовывается». В финале `explode()` из центра экрана разбрасывает частицы салютом. Кнопка «Ещё один» вызывает `reset()`.

## Доступность и адаптивность

- `prefers-reduced-motion`: JS-флаг `RM` отключает циклы сглаживания, частицы, морфинг и задержки; CSS обнуляет переходы и прячет свечение.
- На ширине до 900 px сетки становятся одноколоночными, слайды занимают 84 % ширины, подсказки переносятся, свечение за курсором отключается.
- У всех интерактивных элементов есть `:hover`/`:active` состояния, кнопки-стрелки подписаны `aria-label`, форма использует `label for`.

## Как проверить

Откройте `index.html` в браузере или поднимите любой статический сервер в папке проекта, например `python3 -m http.server 8000`, и зайдите на `http://localhost:8000/`. Для GitHub Pages достаточно положить папку в репозиторий — ссылки относительные.
