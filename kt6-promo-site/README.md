# КТ №6. Промо-сайт ВОЛНА·7

**Задание.** Многостраничный промо-сайт с динамическими эффектами, минимум три страницы, на каждой анимация на JavaScript, которая управляется событиями и мыши, и клавиатуры.

**Решение.** Сайт вымышленного аналогового синтезатора ВОЛНА·7 из трёх страниц. Синтезатор нарисован в SVG функцией `render()` из `js/synth.js`, звук синтезируется в браузере через Web Audio API: два расстроенных осциллятора на ноту, фильтр нижних частот и огибающая.

| Страница | Мышь | Клавиатура |
|---|---|---|
| `index.html` — обзор | синтезатор наклоняется за курсором, клавиши играют по щелчку и ведению; при прокрутке синтезатор приближается, появляются подписи, текст «Звук, который чувствуешь кожей» проявляется, страница темнеет в разделе «Слушайте» | A…K играют ноты и подсвечивают клавиши на рисунке и на экране, 1…4 меняют форму волны на осциллографе |
| `sound.html` — студия | ручки крутятся движением вверх-вниз и колёсиком, клавиши синтезатора с глиссандо, пресеты плавно поворачивают ручки | ноты A…K и W E T Y U, Z и X меняют октаву, 1…4 форма волны, стрелки крутят выбранную ручку |
| `buy.html` — покупка | синтезатор поворачивается перетаскиванием и пружиной возвращается, итог пересчитывается с анимацией | ← → меняют отделку, + и − количество; после заказа рисуется галочка |

Плавность прокрутки сделана без перехвата скролла: в `js/common.js` реальное значение `scrollY` догоняется сглаженным в `requestAnimationFrame`, и от него считаются преобразования. Все анимации отключаются при системной настройке «уменьшить движение».

| Файл | Что внутри |
|---|---|
| `css/style.css` | общая система: цвета, шрифты, навигация, подвал |
| `css/home.css`, `css/sound.css`, `css/buy.css` | стили страниц |
| `js/common.js` | сглаженная прокрутка, появление блоков, смена темы, счётчики |
| `js/synth.js` | рисунок синтезатора, звук, осциллограф |
| `js/home.js`, `js/sound.js`, `js/buy.js` | логика страниц |

Запуск: открыть `index.html`, звук включается после первого нажатия.
