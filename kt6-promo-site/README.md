# КТ №6. Промо-сайт кофейни «Пенка»

Многостраничный промо-сайт вымышленной кофейни. Четыре страницы с общей навигацией, общими стилями и общим скриптом. На каждой странице есть анимация на JavaScript (`requestAnimationFrame`), которая реагирует и на мышь, и на клавиатуру. В правом нижнем углу каждой страницы есть подсказка «Управление» со списком клавиш и действий мыши.

## Как запустить

Открыть `index.html` в браузере. Сборка, сервер и внешние библиотеки не нужны, сайт работает и на GitHub Pages.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html`, `menu.html`, `about.html`, `contact.html` | страницы |
| `style.css` | общие стили всех страниц |
| `js/shared.js` | общие функции, подключается на каждой странице первым |
| `js/home.js`, `js/menu.js`, `js/about.js`, `js/contact.js` | скрипт своей страницы |
| `check.js` | автопроверка фильтра меню и проверки формы: `node check.js` |

## Общий механизм анимации (`js/shared.js`)

- `approach(current, target, speed)` возвращает значение, сдвинутое к цели на долю `speed` (плавное догоняние). Когда разница меньше 0.01, возвращает саму цель.
- `animationLoop(update)` запускает цикл `requestAnimationFrame`, который вызывает `update` каждый кадр, пока она возвращает `true`. Когда всё доехало до цели, цикл останавливается и не тратит процессор. Обработчики событий только меняют цели и снова запускают цикл.
- `reduceMotion` берётся из `matchMedia('(prefers-reduced-motion: reduce)')`. Если в системе включено уменьшение движения, `approach` сразу возвращает цель (без анимации), пар на главной по умолчанию выключен, поле формы не трясётся, а в CSS отключены переходы.
- `ignoreKey(event)` не даёт клавиатурным командам страницы срабатывать, пока пользователь печатает в поле ввода, нажимает сочетание с Ctrl/⌘/Alt или жмёт пробел на кнопке или ссылке.
- Кнопка `☰` открывает навигацию на телефоне (`click` → класс `nav-open` на `body`).

## Страницы

| Страница | Мышь | Клавиатура | Как устроено |
| --- | --- | --- | --- |
| Главная | `mousemove` по первому экрану: параллакс чашки и текста, пар идёт за курсором; `click` выпускает облачко пара | `keydown`: ←/→ наклоняют чашку, ↑/↓ поднимают, пробел включает и выключает пар, Esc возвращает чашку | пар рисуется на `<canvas>`: массив частиц, каждый кадр частица поднимается, растёт и тускнеет, после этого удаляется; чашка двигается через `style.transform` |
| Меню | `mousemove` над карточкой даёт 3D-наклон и блик, `mouseleave` возвращает карточку; `click` по категории | `keydown`: цифры 1–5 выбирают категорию, любая буква или `/` переводят фокус в поиск, Esc очищает поиск; `input` в поиске фильтрует | анимация перестройки сетки по приёму FLIP: запоминаем положение карточек (`getBoundingClientRect`), прячем лишние через `hidden`, измеряем новые положения, сдвигаем карточку на разницу и плавно возвращаем к нулю; появившиеся карточки вырастают из прозрачности |
| О нас | перетаскивание слайдов: `mousedown` на карусели, `mousemove` и `mouseup` на `document`; `click` по стрелкам и точкам | `keydown`: ←/→ листают, 1–4 открывают нужный слайд | лента слайдов сдвигается через `translateX`; во время перетаскивания идёт за курсором, после отпускания при сдвиге больше 60 px листает, иначе возвращается; соседние слайды уменьшены и полупрозрачны |
| Контакты | `mousemove` возле кнопки «Отправить» притягивает её к курсору («магнитная» кнопка), `mouseleave` отпускает | `keyup` в полях: проверка на лету, рамка поля зелёная или красная, плавно заполняется шкала «Готовность формы»; Ctrl/⌘ + Enter отправляет | при отправке с ошибками неверные поля трясутся: смещение `sin(t) × затухание` в течение 0.5 с; при успехе показывается сообщение и форма очищается |

## Логика, которую проверяет `check.js`

- `matches(item, query, category)` в `js/menu.js` решает, показывать ли карточку: подходит ли категория и есть ли текст поиска в названии или описании, без учёта регистра.
- `fieldError(name, value)` в `js/contact.js` возвращает текст ошибки поля или пустую строку: имя не короче 2 букв, email вида `name@mail.ru`, сообщение не короче 10 символов (показывает, сколько осталось).

Последняя строка `menu.js` и `contact.js` в браузере запускает `start()`, а в Node экспортирует эти функции для проверки.
