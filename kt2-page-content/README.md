# КТ №2. Работа с контентом на странице

**Задание.** По данным из `cats.js` вывести информацию о котиках: возраст в правильной форме (год / года / лет), выделить тех, у кого `favourite: true`, показать рейтинг звёздочками.

**Решение.** `main.js` импортирует массив и строит карточки через `createElement`.

- `ageText(age)` выбирает слово по последней цифре и исключению 11–14: 1 год, 2 года, 5 лет, 11 лет, 21 год.
- Любимцы получают значок «Любимец» на фото и цветную рамку карточки.
- Рейтинг из 10 показан пятью звёздами с половинками и подписью `9/10`.
- Сверху переключатель «Все / Любимцы» и сортировка по рейтингу, возрасту или имени.
- По щелчку на карточку открывается окно `dialog` с фото и описанием; закрывается кнопкой «Готово», щелчком по фону или Esc.

| Файл | Что внутри |
|---|---|
| `cats.js` | данные из задания |
| `index.html` | разметка, SVG-иконки звезды и сердца, окно `dialog` |
| `style.css` | сетка карточек, светлая и тёмная тема |
| `main.js` | склонение возраста, звёзды, фильтр, сортировка, окно |

Запуск: через любой локальный сервер или GitHub Pages, потому что скрипт подключён как модуль.
