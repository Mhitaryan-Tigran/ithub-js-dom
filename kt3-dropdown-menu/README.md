# КТ №3. Выпадающее меню на три уровня

**Задание (DOM2, 10 баллов).** Используя навыки работы с атрибутами и классами, реализовать выпадающее меню на три уровня, которое работает по клику. При нажатии на элемент списка, если у него имеется дочерний элемент — разворачивать список, иначе показывать пользователю, что он может пройтись по ссылке.

Решение оформлено как шапка интернет-магазина техники «Вольт»: на десктопе пункты первого уровня лежат в шапке и раскрывают панель, внутри которой второй уровень работает как аккордеон и раскрывает третий; на телефоне меню превращается в боковую панель (drawer) с теми же тремя уровнями. Чистые HTML, CSS и JavaScript, без библиотек и сборки: достаточно открыть `index.html`.

## Файлы

| Файл | Что в нём |
|------|-----------|
| `index.html` | Разметка страницы и вложенные списки меню на три уровня |
| `style.css` | Оформление, анимации раскрытия, адаптив, тост |
| `script.js` | Вся логика: разметка пунктов атрибутами, клики, клавиатура, закрытие |

## Как устроена разметка

Меню — это `nav.menu` с вложенными списками. Каждый уровень — `ul.menu__list` с атрибутом `data-level="1|2|3"`. Каждый пункт — `li.menu__item`, внутри него ссылка `a.menu__link`, а если у пункта есть дочерний уровень, то после ссылки лежит обёртка `div.menu__sub` со следующим `ul`.

```html
<li class="menu__item">
  <a class="menu__link" href="#computers">Компьютеры</a>
  <div class="menu__sub">
    <ul class="menu__list" data-level="2">
      <li class="menu__item">
        <a class="menu__link" href="#computers/laptops">Ноутбуки</a>
        <div class="menu__sub">
          <ul class="menu__list" data-level="3">
            <li class="menu__item"><a class="menu__link" href="#computers/laptops/macbook">MacBook</a></li>
```

В HTML намеренно нет никаких пометок «у этого пункта есть дети, у этого нет»: это определяет скрипт при загрузке, глядя на DOM.

## Какие атрибуты и классы использует решение

| Атрибут или класс | Кто ставит | Зачем |
|-------------------|-----------|-------|
| `data-level` на `ul` | HTML | Уровень списка; CSS по нему оформляет каждый уровень по-своему, JS по нему понимает, что открыт пункт первого уровня |
| `.menu__link--parent` | JS при загрузке | Пункт с дочерним списком; CSS рисует ему шеврон |
| `.menu__link--leaf` | JS при загрузке | Конечная ссылка; CSS рисует стрелку «↗» при наведении |
| `role="button"` | JS при загрузке | Ссылка-родитель ведёт себя как кнопка для скринридера |
| `aria-expanded="true/false"` | JS при каждом клике | Открыт ли дочерний список; CSS по нему поворачивает шеврон, JS по нему решает, открыть или закрыть |
| `aria-controls` и `id` | JS при загрузке | Связывает ссылку с её дочерним списком |
| `title` | JS при загрузке | Подсказка у конечной ссылки с её адресом |
| `.is-open` на `li` | JS при клике | Раскрытый пункт; CSS по нему показывает дочерний список и подсвечивает путь |
| `.is-visible` на тосте | JS | Показывает всплывающее сообщение |
| `.is-open` на `nav.menu` | JS | Открытый drawer на телефоне |
| `has-dropdown`, `drawer-open` на `body` | JS | Затемнение страницы и блокировка прокрутки |

## Как работает script.js

### Переменные в начале файла

- `menu`, `burger`, `closeButton`, `toast` — элементы, найденные через `getElementById`.
- `toastPath`, `toastGo` — строка с путём и ссылка «Перейти» внутри тоста.
- `desktop` — объект `matchMedia("(min-width: 901px)")`: по нему скрипт понимает, десктоп сейчас или телефон, и ловит момент переключения.
- `toastTimer` — номер таймера автоскрытия тоста, чтобы его можно было сбросить.

### Разметка пунктов при загрузке

```js
menu.querySelectorAll(".menu__link").forEach((link, index) => {
  const sub = link.parentElement.querySelector(":scope > .menu__sub");
  ...
});
```

Скрипт проходит по всем ссылкам меню. Для каждой он берёт родительский `li` и ищет в нём прямого потомка `.menu__sub` (`:scope >` означает «только непосредственный ребёнок», чтобы не зацепить вложенные уровни глубже).

- Если дочерний список есть: ему выдаётся уникальный `id` (`submenu-1`, `submenu-2`, …), ссылке добавляется класс `menu__link--parent`, атрибуты `role="button"`, `aria-expanded="false"` и `aria-controls` с этим `id`.
- Если дочернего списка нет: ссылке добавляется класс `menu__link--leaf` и атрибут `title` вида «Перейти: #адрес», взятый из `href` через `getAttribute`.

Это и есть ключевая проверка из задания «если у пункта имеется дочерний элемент» — она выполняется один раз, а результат сохраняется в классах и атрибутах, по которым затем работают и CSS, и обработчик клика.

### `linkOf(item)`

Возвращает ссылку, лежащую непосредственно в `li`. Нужна во многих местах, поэтому вынесена в функцию.

### `closeItem(item)`

Закрывает пункт и всё, что раскрыто внутри него. Собирает массив из самого `item` и всех его раскрытых потомков `.menu__item.is-open`, у каждого снимает класс `is-open` и ставит `aria-expanded="false"`. Благодаря этому, закрывая «Компьютеры», мы автоматически закрываем и раскрытые внутри «Ноутбуки».

### `openItem(item)`

Сначала закрывает уже раскрытых соседей по тому же списку (`item.parentElement.querySelectorAll(":scope > .menu__item.is-open")`), чтобы в один момент был открыт только один пункт уровня — так работает аккордеон. Затем добавляет `is-open` и ставит `aria-expanded="true"`.

### `syncBackdrop()`

Проверяет, есть ли раскрытый пункт первого уровня (`.menu__list[data-level="1"] > .menu__item.is-open`), и через `classList.toggle("has-dropdown", …)` включает или выключает затемнение страницы под выпадающей панелью.

### `closeAll()`

Закрывает все раскрытые пункты меню через `closeItem` и обновляет затемнение.

### `setDrawer(open)`

Открывает или закрывает боковую панель на телефоне: класс `is-open` на `nav.menu`, `aria-expanded` и `aria-label` на кнопке-бургере, класс `drawer-open` на `body` (он запрещает прокрутку страницы, пока панель открыта).

### `pathOf(link)`

Строит путь до ссылки вида «Компьютеры → Ноутбуки → MacBook». Начинает с `li` самой ссылки, затем через `item.parentElement.closest(".menu__item")` поднимается к родительскому пункту, пока они не закончатся, собирая текст ссылок с помощью `unshift` (в начало массива, чтобы порядок шёл сверху вниз).

### `showToast(link)`

Показывает сообщение «Можно перейти по ссылке»: записывает путь в `toastPath`, через `setAttribute("href", …)` подставляет адрес ссылки в кнопку «Перейти», добавляет классу `is-visible`. Предыдущий таймер сбрасывается `clearTimeout`, новый через 4 секунды снимает класс и тост плавно исчезает.

### Обработчики событий

**`menu` — `click`.** Один обработчик на всё меню (делегирование событий). `event.target.closest(".menu__link")` находит ссылку, по которой кликнули; если клик был не по ссылке, выходим. `preventDefault()` отменяет переход по `href`. Дальше ветвление по классу:
- у ссылки есть класс `menu__link--parent` — читаем `aria-expanded`; если `"true"`, зовём `closeItem`, иначе `openItem`. Если пункт лежит в списке первого уровня (`item.parentElement.dataset.level === "1"`), обновляем затемнение;
- иначе это конечная ссылка — зовём `showToast`.

**`menu` — `keydown`.** Ссылка с `role="button"` по Enter срабатывает сама, но пробел по умолчанию прокручивает страницу. Обработчик ловит пробел на ссылке-родителе, отменяет прокрутку и вызывает `click()`, так что с клавиатуры меню раскрывается и Enter, и пробелом.

**`menu` — `focusout`.** Если на десктопе фокус клавишей Tab ушёл из меню наружу (`relatedTarget` есть и не внутри `menu`), раскрытая панель закрывается, чтобы не висеть над страницей.

**`burger` — `click`.** Переключает drawer: читает `aria-expanded` у кнопки и вызывает `setDrawer` с противоположным значением.

**`closeButton` — `click`.** Крестик внутри drawer: закрывает все пункты, прячет панель и возвращает фокус на бургер.

**`toastGo` — `click`.** Нажатие «Перейти» прячет тост; сам переход по ссылке выполняет браузер.

**`document` — `click`.** Клик мимо меню. Если цель клика внутри `menu` или это сам бургер — ничего не делаем, иначе закрываем все пункты и drawer.

**`document` — `keydown`.** Клавиша Escape. Запоминаем, был ли открыт drawer и какая ссылка первого уровня была раскрыта, закрываем всё и возвращаем фокус: на бургер, если был открыт drawer, или на ту ссылку, панель которой только что закрыли, чтобы пользователь с клавиатуры не терял место.

**`desktop` — `change`.** При переходе через точку 901 px (поворот телефона, изменение окна) всё закрывается, чтобы раскрытая панель десктопа не превратилась в странно открытый drawer и наоборот.

## Как работают анимации (CSS)

- **Третий уровень и drawer.** Обёртка `.menu__sub` — это grid с `grid-template-rows: 0fr`, при `.is-open` становится `1fr`; вложенный `ul` имеет `min-height: 0` и `overflow: hidden`. Так высота анимируется чисто на CSS без измерений в JS. Параллельно у списка меняется `opacity`, а `visibility: hidden` у закрытого списка убирает его ссылки из обхода Tab.
- **Панель первого уровня на десктопе.** Та же обёртка, но `position: absolute` под пунктом шапки, появляется через `opacity` и `transform`.
- **Шеврон.** Псевдоэлемент `::after` у `.menu__link--parent`, поворачивается селектором `[aria-expanded="true"]::after` — то есть прямо по атрибуту, который ставит JS.
- **Подсветка пути.** Селекторы вида `.menu__item.is-open > .menu__link` красят раскрытые пункты акцентным цветом на каждом уровне.
- **Стрелка у конечных ссылок.** `.menu__link--leaf::after` с символом «↗» появляется при наведении и фокусе.
- **Телефон.** В `@media (max-width: 900px)` `nav.menu` становится фиксированной панелью слева со сдвигом `translateX(-100%)`, класс `is-open` выдвигает её; показывается бургер и шапка панели с крестиком.
- `prefers-reduced-motion` отключает все переходы для тех, кто просил систему убрать анимации.

## Как проверить

1. Открыть `index.html` в браузере (или опубликовать папку на GitHub Pages).
2. Нажать «Компьютеры» — откроется панель, у пункта повернётся шеврон, страница затемнится.
3. Нажать «Ноутбуки» — раскроется третий уровень, путь подсветится синим.
4. Нажать «MacBook» — снизу появится тост «Можно перейти по ссылке: Компьютеры → Ноутбуки → MacBook» с кнопкой «Перейти».
5. Нажать «Настольные» — «Ноутбуки» свернутся, раскроется новый пункт.
6. Клик по странице или Esc закрывает всё; Tab, Enter, пробел и Esc работают с клавиатуры.
7. Сузить окно до 900 px и меньше — вместо строки меню появится бургер и боковая панель с теми же тремя уровнями.
