# КТ №3. Выпадающее меню на три уровня

**Задание.** С помощью атрибутов и классов сделать меню на три уровня, которое работает по клику. Если у пункта есть дочерний список, он разворачивается, иначе пользователю показывается, что по пункту можно перейти.

**Решение.** Меню каталога магазина «Вольт» в шапке. Пункт с вложенным уровнем — это кнопка с `aria-expanded` и `aria-controls`, пункт без вложений — ссылка `a.leaf`.

- Щелчок по кнопке переключает класс `is-open` у её `li` и атрибут `aria-expanded`; соседние открытые пункты закрываются.
- На компьютере первый уровень открывает панель под шапкой, второй уровень раскрывает третий справа колонкой.
- На телефоне меню открывается кнопкой-бургером на весь экран, уровни раскрываются друг под другом.
- Ссылки помечены стрелкой вправо, при наведении показывают адрес. Щелчок по ссылке закрывает меню и показывает выбранный раздел с цепочкой «Вольт › Компьютеры › Ноутбуки» и адресом ссылки.
- Esc закрывает последний открытый уровень, щелчок мимо меню закрывает всё.

| Файл | Что внутри |
|---|---|
| `index.html` | вложенные списки трёх уровней |
| `style.css` | панель, колонки, мобильная версия, анимации раскрытия |
| `script.js` | переключение классов и атрибутов, переход по ссылке, Esc |

Запуск: открыть `index.html`.
