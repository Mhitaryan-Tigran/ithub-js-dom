# КТ №1. Таблица с генерацией чисел

**Задание.** Создать массив из 30 случайных чисел от 0 до 99, построить по нему таблицу 5×6 тегом `table`, ячейки с числом 50 и больше покрасить в оранжевый. Кнопка с атрибутом `onclick` и текстом «Добавить число» добавляет в таблицу новое случайное число по тем же правилам.

**Решение.** `createTable()` заполняет массив и строит таблицу через `insertRow` и `insertCell`. Функция `foo()` из атрибута `onclick` дописывает число в массив и ставит его в первую свободную ячейку; когда строка заполнена, добавляется новая строка из шести ячеек. Класс `orange` у ячейки ставится, если число не меньше 50. Под таблицей считается статистика: сколько чисел, сколько из них от 50, среднее и максимум. Кнопка «Новая таблица» генерирует массив заново.

| Файл | Что внутри |
|---|---|
| `index.html` | разметка, кнопка с `onclick="foo()"` |
| `style.css` | светлая и тёмная тема по системе, анимация новой ячейки |
| `script.js` | массив, построение таблицы, `foo()`, статистика |

Запуск: открыть `index.html`.
